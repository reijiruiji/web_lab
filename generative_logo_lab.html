03 / Pure CSS

CSS：円を重ねて
幾何学ロゴを作る

<div class="logo">
  <i></i> ... × 6
</div>

.logo i {
  width: 70px;
  height: 70px;
  border: 7px solid white;
  border-radius: 50%;
  position: absolute;
}

.logo i:nth-child(1) {
  transform: translateY(-35px);
}

CSSは「形を部品として組み立てる」のが得意。規則的なエンブレム、タイポグラフィ、UI上の装飾に向く。

04 / Canvas + JavaScript

Canvas：座標と数式から
線を生成する

for (let i = 0; i < 180; i++) {
  const a = i * Math.PI * 2 / 180;

  const r1 = 80 + noise();
  const r2 = 150 + noise();

  const x1 = cx + Math.cos(a) * r1;
  const y1 = cy + Math.sin(a) * r1;

  const x2 = cx + Math.cos(a + 1.2) * r2;
  const y2 = cy + Math.sin(a + 1.2) * r2;

  ctx.moveTo(x1, y1);
  ctx.lineTo(x2, y2);
  ctx.stroke();
}

Canvasでは「点 → 座標 → 線」という発想がそのまま見える。ジェネラティブアートの入り口として理解しやすい。

05 / WebGL

WebGL：GPUに
大量の計算を任せる

HTML Canvas→WebGL Context→Shader→GPU→Pixels

前の例で「WebGLが動かない」原因になりやすいのは、GLSLだけを書いてもWebGLの実行環境は完成しないこと。実際には shader のコンパイル、program のリンク、buffer、uniform、draw call まで接続する必要がある。

Vertex Shader+Fragment Shader=WebGL Program
06 / Working WebGL

まず「動く最小構成」を作る

WebGLを初期化中…

// Fragment Shader
precision mediump float;

uniform vec2 u_resolution;
uniform float u_time;

void main() {
  vec2 uv = gl_FragCoord.xy
          / u_resolution;

  vec2 p = uv - 0.5;
  p.x *= u_resolution.x
       / u_resolution.y;

  float d = length(p);
  d += sin(p.x * 12.0
         + u_time) * 0.025;

  float alpha = 1.0
              - smoothstep(.20, .205, d);

  gl_FragColor =
    vec4(vec3(alpha), 1.0);
}

このデモは外部ライブラリなし。Canvas → WebGL → shader → buffer → uniform → draw の一連の流れを実装している。

07 / GLSL

数学を足すと
ロゴが「生成」される

distance()

中心や図形との距離を求める。円・球・輪郭の基本。

sin() / cos()

周期的な揺らぎを作る。波、回転、変形、アニメーション。

smoothstep()

境界を滑らかにする。ロゴの輪郭やグローに使える。

float d = distance(uv, vec2(0.5));
d += sin(uv.x * 20.0 + u_time) * 0.02;

float shape =
  1.0 - smoothstep(0.25, 0.255, d);
08 / Generative Logo

円 → ノイズ →
有機的なロゴ

「完成した画像」を置くのではなく、輪郭を数式で定義する。

distance
   ↓
sin / noise
   ↓
smoothstep
   ↓
fragment shader
   ↓
animated logo

時間 u_time を加えれば、同じロゴが呼吸するように変形する。

09 / Particle Logo

粒子がロゴを
「形成する」

Canvasなら数千粒子から始めると仕組みを理解しやすい。WebGLなら粒子数を大幅に増やし、GPUで処理する方向へ発展できる。

10 / Roman Sculpture

「困ったら顔」
を作品にする

ローマ彫刻の顔は、生成表現の題材として強い。輪郭・陰影・粒子・ノイズ・光の変化が一つのモチーフに集約できる。

3D Face→Three.js→WebGL→GLSL→Particles / Light / Noise

最終作品では「静止画の顔」ではなく、粒子から顔が現れ、マウス操作で崩れ、時間とともに再構築されるロゴを目標にすると、WebGLを学ぶ理由が明確になる。

11 / React × WebGL

仕事の技術へ
つなげる

React→Three.js→WebGL→GLSL 
function GenerativeLogo({
  speed,
  noise,
  mouseInteraction
}) {
  return (
    <WebGLCanvas
      speed={speed}
      noise={noise}
      interactive={mouseInteraction}
    />
  );
}

ReactはUI・状態・コンポーネントを管理し、Three.js / WebGL側は描画を担当する。これなら「WebGL作品」と「フロントエンド実装」を別物にせず扱える。
