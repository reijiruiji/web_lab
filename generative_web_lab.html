Generative Web Lab

状態変化を、
コードで演出する。

Pure CSS → Canvas + JS → WebGL/GLSL の順に難度が上がる。ギャラリー内のシェーダーはすべてコードを直接編集して「実行」ボタンで再コンパイルできる。壊しても「初期コードに戻す」でいつでもやり直せる。

基礎 / Pure CSS

CSS：円を重ねて
形を組み立てる

DOM要素とCSSの transform / border-radius / clip-path だけで幾何学的なマークが作れる。得意なのはUI装飾・幾何学ロゴ。粒子やノイズのような「生成される」表現には向かない。

基礎 / Canvas + JS

Canvas：座標と乱数から
線を生成する

「角度 → 座標 → 線を引く」がジェネラティブアートの基本形。JavaScriptのコードを直接編集して再生成できる。CPUで1本ずつ計算するため、数千本を超えると重くなりやすい。

コードは ctx, w, h, t(コンテキスト・幅・高さ・経過秒)を使って毎フレーム呼ばれる関数として実行される。

基礎 / WebGL

WebGL：GPUに
ピクセル単位で計算させる

JavaScriptで1本ずつ描くのではなく、GPUに「この数式で画面全体を計算して」と渡す。この先のギャラリーは全部この最小構成(頂点シェーダー固定・フラグメントシェーダーのみ編集)がベースになっている。

Canvas→WebGL Context→Vertex Shader→Fragment Shader→Program→Draw

distance() / sin() / smoothstep() の3つを覚えるだけで、円・波・輪郭のほとんどが作れる。

ギャラリー / Water

水：三角関数の重ね合わせで
光の屈折を作る

sin波を複数の周波数で重ねて、深海色→浅瀬色→泡色へ mix する。ノイズ関数を使わないので軽く、コンパイルも壊れにくい。

向いているサイト：プール・海・水族館・リゾート

転用のコツ：3色(deep/shallow/foam)を変えるだけで「温泉」にも「氷結した海」にもなる。

ギャラリー / Fire

炎：フラクタルノイズの
乱流で揺らめきを作る

fbm(ノイズを何層も重ねたもの)を上方向に流し、明るさのしきい値で炎の輪郭を切り出す。パーティクルを使わずGPUで1ピクセルずつ計算しているので、粒子数を気にせず高解像度でも軽い。

向いているサイト：キャンプ・焚き火・暖炉・アウトドアギア

転用のコツ：色を紫にすると「魔法のエフェクト」、上下反転して灰色にすると「煙」になる。

ギャラリー / Lightning

雷：ノイズで折れ線を歪ませ
発光として描く

座標のy位置ごとにノイズでx位置をずらし、その線までの距離の逆数を明るさにすることでネオンのような発光を作る。一定間隔でシード値(seed)が切り替わり、稲妻が生成し直される。

向いているサイト：宇宙・ロケット・先端技術・ガジェット企業

転用のコツ：色を緑にすると「基盤の電流」、横向きにすると「データ転送のライン」になる。

ギャラリー / Flora

草花：極座標の花びらを
時間で開かせる

中心からの角度と距離(極座標)でcos波の花びら形状を作り、時間で半径をゆっくり広げることで「開花」に見せる。再帰的な枝ではなく、1つの数式だけで完結しているので軽い。

向いているサイト：植物園・公園・農園・サステナブル系ブランド

転用のコツ：白×氷色にすると「霜の結晶」、赤系にすると医療系の血管・神経のようなビジュアルにもなる。

ギャラリー / Snow

雪：タイル状ハッシュで
粒を降らせる

画面をグリッド状に分割し、セルごとにハッシュ関数で粒の位置を決めて時間でy方向にずらす。3層重ねることで奥行きのある降雪になる。

向いているサイト：スキー場・冬季イベント・ラグジュアリー系

転用のコツ：速度と揺れ幅を変えるだけで「桜吹雪」「花粉」「灰」にも流用できる。

ギャラリー / Fog & Cloud

霧・雲：ノイズを
ノイズで歪ませる(ドメインワープ)

fbmの結果を、もう一度fbmの入力座標に足し込む「ドメインワープ」という手法で、渦を巻くような自然な霧の流れを作る。低コントラストでゆっくり動かすのがコツ。

向いているサイト：ウェルネス・瞑想・宿泊施設・霊山観光

ギャラリー / Liquid Metal

液体金属：ノイズで歪めた
縞模様を反射に見せる

縦の縞模様(sin)をノイズで歪ませ、コントラストを強くべき乗することで金属の反射バンドのように見せる。本物の環境マッピングではないが、軽量で「それっぽさ」は十分出る。

向いているサイト：自動車・時計・家電などの高級プロダクト系

ギャラリー / Cracks

ひび割れ：ボロノイ分割で
衝撃の広がりを描く

画面をセルに分割し、各セル内にランダムな種点を置いて最も近い種点までの距離(ボロノイ)を計算するとセル境界がひび割れ状になる。中心からの距離と時間を比較して、衝撃が外側へ広がる演出を加えている。

向いているサイト：ゲーム・エンタメ・インパクト重視の演出

Canvas 2D版(参考)
同じ発想をCanvasで書くと
// 中心から放射状に線を伸ばし
// 経過時間だけ表示範囲を広げる
for (line of lines) {
  if (distFromCenter(line) < frontRadius)
    drawLine(line);
}

WebGL版はピクセル単位で境界線を計算するため滑らか。Canvas版は線分の本数がそのまま負荷になるため、本数を絞る必要がある——これが両者の実務上のトレードオフ。

ギャラリー / Aurora

オーロラ：縦方向の
ノイズ帯をゆっくり流す

fbmノイズをx方向に時間でスクロールさせ、明るい部分だけを緑・紫のグラデーションで着色する。上部ほど薄くすることで、カーテンが垂れ下がるような印象になる。

向いているサイト：旅行・北欧ブランド・夜間イベント

ギャラリー / Dunes

砂丘・風紋：sinの重ね合わせで
等高線を作る

複数のsin波を異なる周波数・位相で足し合わせ、mod()で等高線状に切り出す。地形やマップ表現の基本テクニックで、色を変えるだけで「布のシワ」「木目」にも転用できる。

向いているサイト：旅行・砂漠観光地・アウトドアブランド

Canvas 2D版(参考)
同じ発想をCanvasで書くと
// 横方向にsin波を重ねた
// 折れ線を何本も描く
for (row of rows) {
  for (x = 0; x < w; x++) {
    y = row.base + sin(x*f1)*a1
                  + sin(x*f2+t)*a2;
    lineTo(x, y);
  }
}

活用 / Implementation

1つのコンポーネントに
抽象化する

type: water/fire/lightning/flora/snow/fog/metal/cracks/aurora/dunes 
<GenerativeBackdrop
  type="fire"
  intensity={100}
  fallback="canvas"   // WebGL非対応時にCanvas版へ
/>

// 内部では type ごとに事前定義した
// フラグメントシェーダー文字列を切り替えるだけ。
// DOM構造・WebGLセットアップ・resize処理は共通化できる。

今回作った10種類は、頂点シェーダーとJS側のセットアップコードが全部共通。切り替わるのはフラグメントシェーダーの文字列と、uniformにわたすスライダーの値だけなので、コンポーネント化は難しくない。

活用 / Next

次にやること

1. 共通ハーネス化

このページの「シェーダー実行エンジン」部分をそのままReactのカスタムフックに移植する。

2. フォールバック設計

WebGL非対応・低スペック端末向けに、ひび割れ/砂丘で試したCanvas版を他の演出にも用意するか判断する。

3. パレット差し替え

色の3〜4値を業種ごとに変えるだけで転用できる状態を確認済み。案件が来たら配色だけ差し替えて試す。

4. モバイル負荷計測

実機で複数エフェクトを同時に動かした場合のfpsを計測し、同時稼働数の上限を決める。

5. 実案件で1つ試す

今のプロダクトのローディング画面かヒーロー背景に、最も相性の良い1つを実装して反応を見る。
